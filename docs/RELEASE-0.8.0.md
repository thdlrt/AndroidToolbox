# 0.8.0 手机访问全屏与网络诊断一键自检

## 手机访问

- 标题栏新增全屏按钮。全屏后整个屏幕只显示电脑上的 DSH 页面，工具箱标题栏、左侧导航、底部导航和系统状态栏/导航栏都会隐藏。
- 右上角保留一个半透明小圆钮用于退出全屏，系统返回键也可以退出；切换到其他工具时自动恢复工具箱界面。
- 折叠屏展开到内屏、再合拢回外屏，都会保持全屏和当前页面，不会重新加载，也不会重新出现工具箱工具栏。
- 全屏时按屏幕开孔安全区留白，避免摄像头或圆角遮住网页内容；刷新、连接设置等原有操作保持不变。

## 网络诊断

- 新增「一键自检」，不需要填写地址，一次检查设备联网、DNS 解析、IP 直连和网页访问。
- 结果按「✓ 正常 / ! 注意 / × 异常 / – 跳过」逐项显示，并给出对应建议；部分 DNS 或 IP 失败只标注意，不会误判成整网断开。
- 未联网时明确提示先连接 Wi-Fi 或移动数据，并跳过后续检查。
- 保留原「指定地址诊断」，可继续检查指定主机的 DNS、TCP、TLS 和 HTTP；自检和详细诊断都会自动滚到结果区。
- 最近一次结果保存在本机，重新打开页面仍可查看，也可以复制成文本。

详见 [手机访问电脑里的 DSH](POCKET.md) 和 [项目记账与网络诊断](LEDGER.md)。
