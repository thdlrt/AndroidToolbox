# AndroidToolbox 0.6.2

统一数据同步与配置备份，并完善记账操作。

- 记账和网络诊断配置接入可扩展的统一同步管理器，启动自动同步、本地变更合并触发，离线失败退避重试。
- 新增全局手动同步图标，长按查看最近成功时间与错误；普通手机和展开屏均可使用。移除设置里的自动同步面板。
- AI 供应商、功能模型和 API Key 并入配置备份，使用现有 WebDAV 密码加密。Windows 与 Android 共用备份列表；同平台恢复设置与 AI，跨平台仅恢复共享 AI，保留本机专属模型。
- 恢复前预览确认，检查本机配置和连接是否已变化；恢复失败回滚，并兼容旧 Android 备份及旧独立 AI 配置。
- 记账新增近3月、近半年快捷筛选，按包含本月的最近3/6个自然月首日至今天计算。附件继续只加入草稿，保存成功后关闭编辑器。

配套 WinToolbox 0.4.1。已通过 JVM 测试、原生配置恢复事务、普通手机/展开屏布局，以及真实本地 WebDAV 服务上的两端配置与密钥互通测试。短信与取件数据库仍保存在本机，不因自动同步上传。
