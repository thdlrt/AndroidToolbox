# AndroidToolbox 0.6.1

重做移动端界面，改善普通手机、折叠展开和横屏下的排版。

- VPN、文件中转、项目记账、网络诊断和取件助手使用独立图标与配色，首页卡片随宽度调整列数。
- 普通手机使用底部导航，展开屏使用紧凑侧栏，更大窗口显示完整侧栏；横屏侧栏可滚动。
- AI 设置、取件、WebDAV、诊断和 VPN 页面重新分组，按内容宽度切换单栏和双栏。
- 修复导航文字偏移、部分页面边距不一致，以及大字体下中转按钮裁字。
- 修复折叠尺寸变化导致页面重建、未保存输入丢失的问题。

验证：五种模拟器窗口布局、实时收窄及草稿保留检查通过；导航回归 190 项、取件与 AI 配置回归 33 项通过；单元测试 49 项通过、1 项原有跳过。已核验正式安装包版本、包名和历史签名，并在模拟器安装启动。

窗口尺寸适配已在模拟器验证，真实设备的铰链遮挡和厂商跨屏行为尚未实机验证。

下载 `AndroidToolbox-0.6.1.apk` 安装；沿用原签名，版本代码为 12。对应 `.sha256` 文件用于校验下载完整性。
