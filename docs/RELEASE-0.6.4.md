# 安卓工具箱 0.6.4

- 替换原生 Spinner 弹出层，模型供应商、接口类型、记账筛选及表单、取件分类、VPN 范围等下拉菜单统一为白色圆角、蓝色选中行与勾选标记；弹出菜单与输入框同宽，选择后立即收起。文件中转的更多菜单同步调整。
- 取件助手新增“取件设置”：可启用打开软件自动读取过去 1–93 天的短信（含今天），默认关闭。使用已配置的多模态 AI 自动分析、去重并入库。
- 自动读取从应用打开时触发，无需先进入取件页面；60 秒内短时返回及并发请求合并，手动和自动导入共用去重锁，避免重复调用 AI。
- 缺少短信权限时在取件设置中提示并申请授权；网络或 AI 失败不会标记为已处理，重新打开或重新保存设置可重试。自动读取开关仅作用于当前手机，不随跨端配置恢复自动开启。

已验证：本地 HTTP 模拟接口的启动读取、HTTP 503 失败重试、真实模拟器短信读取及 SQLite 入库、重复来源跳过、短时重入和关闭开关；单元测试、下拉菜单实际选项切换、天数范围验证和手机/展开屏布局检查。保留历史包名与签名，支持覆盖更新。
