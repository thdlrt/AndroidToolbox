# 安卓工具箱 0.3.2

- 适配折叠屏和平板：宽屏采用左侧功能导航、右侧内容；窄屏使用底部导航。切换窗口尺寸保留中转目录、搜索、排序和选择状态。
- 重做文件中转站：点击文件直接打开，长按多选；排序、新建、清理、日志和路径设置收进菜单，减少主界面的按钮。
- WebDAV 连接统一在设置中管理，中转站只需指定远端路径。旧版连接和路径自动迁移，不用重新填写密码。
- 统一工具、导航和文件图标、卡片、按钮与选中状态；新增自适应启动图标和主题图标，修正通知图标。
- 优化状态刷新，只有文字变化时才更新，减少无意义重绘。

支持从其他应用打开或分享文件后自动上传；已下载文件可直接打开、分享或删除本机缓存。

保留包名和原发行签名，可覆盖旧版本。最低 Android 10。下载 `AndroidToolbox-0.3.2.apk` 安装，或在旧版的设置中检查更新；安装仍需系统确认。

已通过 19 项单元/协议测试、签名构建，以及 Android 15 模拟器的手机/方形宽屏、动态尺寸切换、跨应用上传、后台队列、文件打开和缓存管理验收。实体折叠屏的物理铰链避让及厂商特殊分屏策略尚未实测。
