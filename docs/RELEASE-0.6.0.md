# AndroidToolbox 0.6.0

新增 AI 取件助手与简化的多供应商模型设置。

- 授权后按最近1/2/3/7天或自定义日期读取收件箱，勾选短信后确认发送给大模型解析；支持粘贴和图片导入。
- 结构化结果保存至本机数据库，重复来源跳过；待取列表按地址、柜/站点、快递公司分类排序。
- 已取件归档并可撤销；后续提醒不复活旧条目，同码复用保留待核对候选。
- 设置中管理供应商，文本和图片分别选择服务与模型；不固定绑定厂商或模型。
- AI 配置与 API Key 可和 WinToolbox 0.4.0 双向加密同步，复用统一 WebDAV 密码和自动子目录，不上传短信数据库。

详见 [取件助手使用说明](PARCELS.md)。短信权限受系统和安装器限制，不能授权时可使用粘贴/图片入口。首次启用及每次发送均需明确操作，不在后台读取短信。模型调用测试使用模拟接口，未替用户调用付费服务。
