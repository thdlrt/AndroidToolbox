# 取件助手与 AI 配置

## 使用

1. 设置 → AI 设置：添加一个或多个 OpenAI 兼容供应商，填写 API 地址和 Key。
2. 选择一个支持文字和图片的多模态供应商及模型 ID。短信和图片共用此模型，配置后即可使用。
3. 取件助手点击“＋ → 扫描短信”，选择最近 1、2、3、7 天或自定义日期，点击“扫描并分析”并授予短信权限。所选范围尚未处理的短信会发送给配置的 AI，提取后自动入库。
4. 模型返回固定字段后写入本机 SQLite：来源、取件码、运单、公司、地点、柜/站点、状态和截止提示。默认只看待取，可按地点、柜/站点、公司或时间分类排序。
5. 点击“已取件”归档，归档中可撤销。重复扫描跳过已处理来源；后续提醒不会自动恢复已取状态。同码复用等无法确定的情况保留待核对候选。

没有短信权限时可粘贴导入。图片通过系统相册选择，使用同一多模态模型，结构与来源校验通过后直接入库。不会在后台读取或监听新短信，不请求发送/删除短信权限。Android 将 READ_SMS 列为受限制权限，部分系统或安装器可能不允许授予；这种情况下使用粘贴/图片入口。

短信内容不由机械模板分类，全部由模型提取。程序只负责来源/格式/完整码校验、幂等入库和取件状态，不执行短信中的网址或指令。一次请求最多20条/12000字符，超过时分批；返回不完整、截断或失败不将本批标为已处理，可重试。

## 与 PC 同步配置

AI 设置集中在「WebDAV 与备份 → 配置备份」中随配置一起上传、预览和恢复。两端使用同一 WebDAV 地址、账号、密码和根目录，新备份保存在 `<根目录>/config-backups/shared`。恢复电脑备份时只导入共享 AI 设置；手机首页和 NAS 偏好保留。旧版 AI 备份仍显示在此列表。

备份未包含的本机取件模型继续保留。供应商同名 ID 但地址或密钥不同时，会保留独立的本机供应商，避免取件角色引用错误密钥。

配置和 API Key 采用 PBKDF2-HMAC-SHA256（200000 次）派生 AES-256-GCM 密钥，复用 WebDAV 连接密码；API Key 在各端重新用本机安全存储加密。修改 WebDAV 密码后，需从保留配置的设备重新上传。

AI 配置同步不包含短信、图片或取件数据库。模型判断可能出错，可以查看原始来源核对；未调用真实付费模型验证解析准确率，当前自动化验收使用合成短信与模拟接口。
