# 安卓工具箱 0.6.12

- 新增「取件助手 → ＋ → 扫描短信 → 仅检查读取 → 查看原文」，可查看系统接口实际返回的短信，点开完整正文并复制。未生成记录的重试弹窗同样提供此入口。显示范围内最近100条；查看不调用 AI、不改变处理标记，空正文不能复制。
- 日志新增读取及 AI 输入概要：正文长度、空正文、丰巢标记、取件码标签、取件指令、格式字符和完整模板数量；增加受限的常见模型名、协议类型与规则未命中提示。短信全文仍仅在原文界面本机展示，不写入日志。
- 短信读取改为按字段名定位 ID、时间、发送方和正文，避免系统返回列顺序不同导致取错字段。
