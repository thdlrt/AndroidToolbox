# 安卓界面与交互整理（0.6.3）

## 公共组件

使用 Material Components 1.13.0 与 AndroidX AppCompat。`ToolUi` 提供蓝白配色的按钮、浮动标签输入框、下拉选项、圆角卡片与状态标签；对话框统一为 MaterialAlertDialogBuilder。系统照片选择使用 Android 13+ Photo Picker，旧版使用相册 ACTION_PICK。

窄屏使用底部导航，宽屏使用常用工具侧栏。常用状态与首页一致，全部工具和设置始终可达。全局同步图标固定在内容底部，成功显示自动消失的提示；各业务页面不提供独立 WebDAV 配置或立即同步按钮。

## 页面

- 记账：日期分组、独立条目卡片、区间收入/支出按币种汇总，区分金额、项目、分类、报销状态与附件。保留分摊金额。本月/近3月/半年/全部快捷筛选，日期选择器；编辑表单自适应排列，附件通过添加菜单选择相册、拍照或文件。附件导入中禁止保存，成功保存关闭弹窗。
- 取件：主页面保留清单、状态/排序和加号。加号打开扫描短信、粘贴、相册导入；扫描页选日期并提交即分析，移除连续确认和图片说明步骤。AI 结果经过既有结构与来源验证后入库并去重；图片不再强制人工确认。归档可撤销。
- AI：移动端仅显示一个多模态供应商和模型。旧配置优先使用 parcel_vision / vision，兼容 parcel / chat 回退；保存会同步写入两个旧角色以保持跨端格式兼容。运行时文本与图片均使用同一多模态角色，不再检查旧 ai_enabled 开关。
- 网络诊断：参数折叠，配置管理收进菜单，报告独立展示；移除业务页 WebDAV 设置。
- 文件中转、VPN、首页、全部工具、设置与配置备份：统一公共控件、导航和弹窗，调整状态与操作层级。
