# 0.9.0 Codex 远程（HAPI）

- 新增「Codex 远程」：在安卓工具箱内使用电脑上的 HAPI 网页，发消息、查看输出和历史、回答提问与审批。
- 电脑地址和访问令牌独立保存；支持粘贴 HAPI token 链接，分离令牌后加载网页，不把令牌放入网页地址。更换服务器不复用旧令牌。
- 支持全屏、折叠屏布局、返回键、切换工具保留页面和安卓系统附件选择器。保留原有 DSH「手机访问」。
- 提供 Windows 脚本 `codex-remote.ps1`，固定安装 HAPI 0.30.7 与独立 Codex CLI 0.164.0，包含启动、状态、连接信息和停止命令；不替换现有桌面 Codex。

## 开始使用

先下载本 Release 的 `codex-remote.ps1`，按[连接说明](https://github.com/thdlrt/AndroidToolbox/blob/v0.9.0/docs/CODEX-REMOTE.md)安装并启动电脑端，再在安卓工具箱「Codex 远程」中填写电脑地址及访问令牌。

## 验证与限制

Windows 的真实 HAPI + 官方 Codex 链路、隔离模型响应与远程提问回答通过；安卓模拟器的真实 HAPI 登录、会话历史、令牌隔离和全屏检查通过。本机实际模型 `gpt-6.1-sol` 已返回「连接正常」。APK 沿用历史签名，发布前验证包名、版本、签名与 SHA-256。

本版使用 HAPI 管理的会话，不接管任意已运行的官方桌面聊天。同一局域网可直连；外出需其他系统 VPN / Tailscale 或自行部署的 HTTPS 入口。工具箱自带回家 VPN 排除自身。实体手机、外网连接和网页语音尚未验收。
