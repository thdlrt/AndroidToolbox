# 安卓工具箱 0.3.1

新增文件中转站，并完善跨应用文件传递。电脑和手机填写相同的 WebDAV 地址及中转目录，即可交换文件。

- 在文件管理器、聊天或其他应用中选择“打开方式 → 文件中转站”或“分享 → 文件中转站”，自动上传收到的文件；支持多文件分享与后台排队。
- 未配置连接时先设置，测试成功后继续上传；上传保留原文件，同名不覆盖。
- 浏览、新建目录、搜索与排序；单个或批量删除远端文件，按时间预览清理，删除前复核文件版本。
- 下载到系统目录，或交给其他应用打开/分享。新增“已下载”入口，缓存可再次打开、分享或单独删除。
- 上传记录放在独立日志页；修复忙碌时分享文件可能丢失、返回上级目录显示旧列表等问题。

Android 10+，包含四种 CPU 架构。包名 `net.lanbridge.android`，版本代码 6，沿用历史发行签名，可覆盖升级并保留配置。APK 不包含用户账号、密码或测试连接。

验证：19 项单元/协议测试通过，1 项真实 NAS 测试按默认配置跳过；Android lint 无错误。Android 15 模拟器完成跨应用真实内容 URI 授权、打开/分享上传、排队及后台上传、下载内容核对、跨应用读取、删除和覆盖升级检查。未操作实体手机，未验证手机到真实 NAS 的网络条件。

外部应用打开的是只读下载副本，编辑不会自动写回远端。系统强制结束进程后不会自动恢复上传队列，需要重新分享。目录递归上传和批量下载暂不支持。
