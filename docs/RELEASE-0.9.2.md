# 0.9.2 实时电脑会话

「手机访问 → Codex」默认直接显示桌面会话：运行中、待处理、空闲状态，点开查看当前输出、加载更早记录、发送消息到同一桌面会话。每 3 秒自动更新，搜索仅作可选筛选；不再需要先搜索、导入 HAPI。

窄屏为列表／聊天切换，宽屏为左右两栏，支持自动跟随、工具输出展开与全屏。DSH 仍在同一个入口；顶部 HAPI 可切回原网页，用于它自己管理的会话、提问和审批。

电脑服务也需要更新：将本 Release 的 **codex-remote.ps1 和 codex-desktop.mjs 一起下载**，放在同一目录，然后执行：

```powershell
& .\codex-remote.ps1 -Action Start -Root 你的原安装目录
```

原地址和令牌保留。默认 HAPI 为 3006，实时桌面为 3007；安卓仍填写原 3006 地址，自动连接下一端口。保持桌面 Codex 打开，受信任网络需能访问两个端口。本次开发机已完成部署。两个脚本的 SHA-256 校验文件均随附。

桌面连接使用已安装的 app-tools，沿用桌面的运行进程，不另启 app-server 或导入历史。显示桌面最近 50 个会话及置顶；当前接口按轮次提供输出快照，暂未提供逐 token 推流、停止、审批或交互选项的远程操作，后面三项需在电脑端处理。接口随桌面版本可能变化，断线会显示错误并重连。

验证：114 项 JVM 测试（0 失败、1 项既有跳过）、8 项 Node 桥接测试、17 项 Android 15 实时页面检查通过；真实桌面读取到 25 个会话，当前对话状态为 active、轮次为 inProgress。真实桌面验证为只读；发送、重复提交和失败路径在隔离 fixture 验证，没有向用户其他聊天发送测试消息。实体手机、外网及语音未验收。

[连接说明](https://github.com/thdlrt/AndroidToolbox/blob/v0.9.2/docs/CODEX-REMOTE.md)。外出仍需其他系统 VPN/Tailscale 或自行部署的 HTTPS 私有入口；工具箱自带回家 VPN 排除自身。

回归补充：真实隔离 HAPI＋官方 Codex 协议链路通过；另30项 Android HAPI／DSH回归检查通过（登录、原生历史载入、附件、两个后端保留、全屏和折叠）。
