# 0.5.0 · 统一 WebDAV 与配置备份

## 改动

- WebDAV 设置统一为地址、用户名、密码、一个根目录。所有工具自动创建并使用固定子目录，不再要求分别配置记账和中转路径。
- 打开软件继续自动合并记账与诊断配置；统一设置提供同步状态、立即重试和旧目录迁移状态。
- Android 配置备份支持手动上传、查看与确认后恢复，覆盖首页常用项、NAS 地址/用户名及 VPN 模式。
- 配置备份明确排除密码、设备 Keystore 密文、记账记录、附件、中转文件、缓存和日志；恢复保留当前 WebDAV 连接/根目录，恢复前保存本机配置副本。NAS 账号变化时需重新输入密码。
- 升级优先沿用原记账根目录。旧中转文件安全复制到固定的 `file-relay`，不同内容的同名文件放入稳定 `legacy-<来源标识>` 子目录；源文件保留。
- 更换统一根目录后继续迁移旧中转目录中新上传的文件，并导入旧根目录中尚未下载的不可变记账操作与附件。任务固定连接快照，不随后续设置变化改变目标。

## 验证

- JVM：35 个测试，34 通过，1 个真实 NAS 测试按原策略跳过。
- 指定模拟器 `emulator-5560`：统一设置 UI 7 项检查通过。
- 真实合成 WebDAV：Android 旧目录迁移、配置上传/列表/下载/恢复，当前连接和记账不被恢复覆盖均已验证；PC 与 Android 使用相同的根目录和固定服务目录。
- 保留包名和原签名，支持覆盖升级。未操作用户手机。
