# 安卓工具箱 0.6.5

- 修复取件助手分批导入后同一站点出现多个分类的问题：每次入库统一地点格式，站点名与室内、室外、柜号分开保存和显示。
- 升级时自动整理已有待取和归档记录，保留柜位、取件码、原始来源和已取状态，不合并不同柜位的包裹。
- 新增「取件助手 → 取件设置 → 整理地点」：勾选同一站点的简称或别名，填写统一名称，预览后确认。规则保存在本机，后续导入沿用，无需再次调用 AI。
- 按柜查看时同时显示所属站点，避免不同站点的同号柜出现在同一分类。

已验证：70 项单元/协议测试通过，1 项真实 NAS 测试按默认设置跳过；41 项取件数据库断言覆盖分批导入、旧库升级、别名持久化、同码不同柜、归档保护和失败回滚；模拟器完成地点选择、预览、返回修改与确认整理。签名构建和 lintVital 通过，保留历史包名与签名，支持覆盖更新。

模型仍可能使用新的简称或给出矛盾信息，此时可查看来源并手动整理；本次未使用真实付费模型或实体手机验收。
