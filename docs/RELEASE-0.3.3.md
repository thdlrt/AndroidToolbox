# 安卓工具箱 0.3.3（本地构建）

- 修复折叠屏侧栏切换时整个窗口滑动的问题。侧栏固定在同一个窗口，只有右侧内容进行短暂淡入。
- 中转站、VPN、首页和设置切换时复用页面，保留中转目录、选择状态及未提交的表单输入。
- 隐藏页面暂停状态轮询；窗口重建后忽略旧文件请求的界面回调，避免折叠切换时更新失效页面。
- 保留外部应用打开/分享文件的入口及 URI 授权，接收后仍自动上传。

包名与历史签名不变，版本号 0.3.3 / versionCode 8，可覆盖安装。本次生成本地签名安装包，尚未发布 GitHub Release。

已在指定 Android 15 模拟器验证导航对象与窗口复用、连续 30 次切换、表单保留、窗口重建、返回行为和跨应用上传。实体折叠屏尚未实测。
