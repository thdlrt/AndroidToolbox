# 文件中转站

工具首页或全部工具 → 文件中转站 → 连接设置，填写和电脑端相同的飞牛 WebDAV 地址、账号、密码及远端缓存目录，例如 `共享名/文件中转站`。点击“保存并测试连接”，会保存当前输入并检查目录；只创建最后一级目录，父共享目录必须已存在。

密码独立使用 Android Keystore 加密，不沿用或修改回家 VPN 的登录配置，也不随 APK 分发。客户端不忽略 HTTPS 证书错误，不携带凭据跳转到其他地址。

- 点文件夹进入，支持返回上一级、新建文件夹；可搜索当前目录，按时间、名称或大小排序，目录优先显示。
- “上传文件”使用系统文件选择器，可多选并上传到当前目录。其他应用的“打开方式”或系统分享菜单选择“文件中转站”，会自动上传到中转根目录。支持单文件、多文件以及 ClipData 文件授权。仅接收内容文件 URI，不把网页链接或纯文本分享当作文件上传。
- 首次没有连接时先填写连接；连接测试成功后继续上传刚才收到的文件。传输中再次分享会排队，最多等待 16 项任务；排队时固定目标连接，后续改设置不会改变已排队文件的去向。上传原文件始终保留。
- 上传保留本地文件。先上传临时文件，再用禁止覆盖的 MOVE 发布；已有同名项目报错，不覆盖。兼容部分飞牛 WebDAV 地址要求路径形式 Destination 的情况。
- 点击文件可以打开、下载到系统选择的位置，或分享给其他应用。打开/分享使用只读 `content://` 临时授权，不暴露密码或应用内部其他文件。
- “已下载”列出本机缓存，支持再次打开、分享或确认删除缓存；再次打开不需要重新下载。删除缓存不影响远端。“下载到…”可另存到 Downloads 等系统位置，由系统文件管理器管理。
- 点击文件选择“删除远端文件”，或勾选后“删除所选”；确认后永久删除远端文件，保留本机副本。删除前复核版本并发送 If-Match，文件变化则跳过；不递归删除目录。
- 上传日志在独立二级页面，保留最近 100 条记录；失败可以重新选择文件上传。
- 清理支持 1 天、1 周、30 天、90 天，预览后确认删除。仅删除有强 ETag 和可靠修改时间的文件，执行前复核并使用 If-Match；变化的文件跳过，不删除目录。预览 10 分钟后失效。

传输由前台服务运行，切换其他应用后仍可继续，在中转站可取消。应用被强制停止、系统结束进程或后台时限耗尽时不会自动恢复任务；需重新操作。Android 15 的系统后台传输时限同样适用。

当前支持文件上传/下载和远端目录浏览，不提供本地文件夹递归上传、目录批量下载或双向同步。文件交给其他应用的是只读缓存副本，外部应用编辑不会自动写回 NAS。缓存也可以通过 Android 应用存储设置清除。

## 0.3.1 跨应用验收

使用 Android 15 的指定模拟器与独立测试应用（不同 UID、非公开文件 Provider）验证：冷启动 ACTION_VIEW 自动上传、ACTION_SEND、多文件分享、ClipData-only、重复 URI 去重、上传中再次分享排队、返回桌面后继续传输；逐字节核对上传内容。发行 APK 也完成了系统选择器保存到 Downloads 的内容核对。打开及分享的缓存由另一测试应用实际读取，批量远端删除和本机缓存删除互不影响。

复现跨应用上传：构建 `:relay-fixture:assembleDebug` 并安装到明确选定的测试模拟器，运行 `python scripts/relay-test-server.py`，在中转站配置该脚本注明的模拟器测试地址和测试账号，再运行 `python scripts/smoke-relay-incoming.py --serial emulator-5554`。测试应用独立打包，不包含在正式 APK 中。

## 0.3.0 验证

使用明确选定的 Android 15 `emulator-5554` 和本机 WebDAV 测试服务：

- 从 0.2.1 覆盖安装，原包名和发行签名保持一致。
- 保存连接、目录浏览、系统选择文件上传、下载到 Downloads 并对比内容通过。
- 系统分享选择器能显示文件中转站；分享回中转站收到文件并需确认上传，同名拒绝覆盖通过。
- 清理预览只包含旧文件，确认后删除旧文件并保留新文件和目录。
- 新增协议测试涵盖路径边界、XML 实体拒绝、重定向拒绝、飞牛 MOVE 502 兼容回退、版本校验下载和清理并发保护。

没有在用户实体手机或手机到真实 NAS 的网络上验收；测试服务不使用用户凭据。
