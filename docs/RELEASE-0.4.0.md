# AndroidToolbox 0.4.0

- 新增项目记账：创建、修改、归档项目；按项目和日期查看收支。AI报销是内置项目，其他项目可独立记录。
- 支持调用系统相机拍照、系统文件选择器添加票据附件，保留完整图片并校验附件内容。
- 与 WinToolbox 0.2.0 通过统一 WebDAV 连接自动合并账目、项目、附件和诊断配置。打开软件即同步；支持离线录入、变更重试、同字段冲突选择和删除防恢复。
- 新增网络诊断：DNS、TCP 连接耗时与成功次数、TLS 证书、HTTP 响应。诊断对应工具箱直连网络，当前工具箱自身不经过其回家 VPN。
- 保留折叠屏/平板左侧导航、手机底部导航和原有文件中转功能。

## 配置

两端填写同一个 WebDAV 连接。Android 记账页的“同步设置”目录需要与 PC 设置的远端目录一致，默认 `WinToolbox`。账本在 `ledger-v1` 子目录中自动合并，无需选择覆盖方向。系统结束应用后，在下次打开继续同步。

## 验证

30 项 JVM 测试通过，1 项真实 NAS 测试按原策略跳过。指定 Android 15 模拟器通过记账界面、真实系统相机和文件选择器、PC 双向 WebDAV 同步、并发冲突与解决、图片校验、删除传播、冷启动自动同步测试。

正式包包名与签名保持一致，已从模拟器中的 0.3.3 覆盖升级至 0.4.0，升级前后 4 份设置文件校验值一致。没有操作用户实体手机；实体机厂商后台策略和真实 NAS 网络仍需按设备使用情况验证。

详见 [使用说明](LEDGER.md) 和 [验证记录](VALIDATION.md)。
