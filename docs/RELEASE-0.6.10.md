# 安卓工具箱 0.6.10

- 新增「设置 → 运行日志」，支持查看、复制和确认后清空，便于排查短信读取、关键词过滤、AI 分类和快递入库问题。日志仅保存在本机，最多两份128 KiB文件，不记录短信正文、取件码、密钥或模型原始响应。
- 新增「取件助手 → ＋ → 扫描短信 → 仅检查读取」。无需配置或调用 AI，即可查看系统收件箱总数、最新收件时间、扫描日期与时区，以及读取、匹配、过滤、已处理跳过和待分析数量；不会修改已处理标记。
- 修复应用跨天后，「今天」及最近2/3/7天快捷扫描范围可能保留旧日期的问题；自定义日期继续保留。
- 扫描结果区分没有读取到短信、关键词未匹配、已处理来源跳过，以及 AI 未生成新记录，避免统一显示“没有”造成误解。

验证：84项单元/协议测试通过，1项真实 NAS 测试按默认策略跳过；14项新增模拟器调试验收通过，并完成既有取件界面、数据库、地点和编辑回归。真实 qwen3.8-flash 中档思考能正确提取一条丰巢通知；具体手机漏读原因仍需本机日志确认。签名构建、lintVital、正式0.6.9覆盖升级及冷启动通过，未操作实体手机。
