# 安卓工具箱 0.6.9

- 新增快递短信快速过滤：默认开启，内置114个关键词，覆盖常见承运商、驿站、快递柜、取件与派送通知及英文用语。在「取件设置 → 短信快速过滤」可查看、编辑、关闭和恢复默认，自动读取与手动扫描共用规则。
- 新增「AI 设置 → 思考强度」：可选模型默认、关闭、低、中、高，按供应商适配思考参数。设置仅保存在本机；模型不支持时明确提示，不静默关闭思考。旧版沿用模型默认，并非强制关闭思考。
- 改进「驿小哥 / 菜鸟速递」等到站通知识别，保留完整分段取件码与原文截止提示。在扫描短信时勾选「重新识别未生成快递记录的短信」，可重试以前漏掉的通知，已有待取和归档记录仍跳过。
- 支持「快递卡片 ⋮ → 编辑信息」，可修改取件码、运单号、公司、地点、柜位和截止提示。保留原始来源、接收时间和归档状态，后续 AI 提醒不会覆盖手动改动的字段。
- 「从剪贴板粘贴」点击后直接读取文字并分析入库，减少一次点击；剪贴板和图片导入不受短信关键词过滤限制。
- 普通手机工具首页改为每行两列，宽屏继续自适应布局。

验证：81项单元/协议测试通过，1项真实 NAS 测试按默认策略跳过；模拟器完成过滤设置、思考参数、短信读取与入库、地点、编辑和既有界面回归。qwen3.8-flash 中档思考已用一条到站通知实测，正确返回完整取件信息；这不代表所有模型的识别准确率。签名构建及 lintVital 通过，未操作实体手机。
