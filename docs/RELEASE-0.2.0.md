# 安卓工具箱 0.2.0

- 将回家 VPN 迁移为安卓工具箱的首个工具。
- 新增工具首页、全部工具、常用项选择、设置和第三方许可。
- 新增 GitHub 正式版检查、下载、SHA-256 和 APK 签名校验、系统安装入口。
- 保留包名、签名及加密登录配置，支持从原 0.1.x APK 覆盖升级。
- 新安装不再预填私人 NAS 和账号；会话检查不再连接个人测试服务器。
- Android 10+，支持 arm64-v8a、armeabi-v7a、x86_64、x86。

VPN 的 TCP-only 限制仍然存在。更新安装需要 Android 系统确认，首次还需允许本应用安装 APK。
