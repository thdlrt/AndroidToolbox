# 0.7.0 手机访问电脑里的 DSH

- 新增「手机访问」：在应用内直接打开电脑上运行的 DSH 网页界面，电脑地址和访问密码在工具里配置一次，之后自动登录。
- 地址支持粘贴，`IP:端口` 与完整 `http://` 地址都识别，非法地址在输入时就给出原因，不会静默失败。
- 会话保存在应用内 WebView 的 cookie 中，有效期 30 天；「连接设置 → 清除登录」可立即清除，密码留空表示沿用已保存的密码。
- 登录过程在真实页面上自动提交，密码错误、连接失败和登录握手失败分别给出对应提示，不假装成功。
- 页面按手机宽度渲染，支持双指缩放；从工具箱切走再回来不会重新加载，输入内容保留。

详见 [手机访问电脑里的 DSH](POCKET.md)。
