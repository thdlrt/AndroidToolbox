# 安卓工具箱 0.2.1

首个公开发行版，将回家 VPN 升级为独立安卓工具箱。

- 工具首页、全部工具、常用项选择、设置和第三方许可。
- 回家 VPN 保持后台运行，支持加密记住登录。
- 应用内检查 GitHub 正式版，一键下载、校验 SHA-256 和签名，并打开系统安装器。
- 沿用旧版包名和签名，支持覆盖升级并保留配置。
- 新安装不预填个人 NAS 和账号。
- Android 10+；arm64-v8a、armeabi-v7a、x86_64、x86 通用 APK。

VPN 需配套 fnOS 局域网桥服务端，仍仅支持 IPv4 TCP；普通 UDP、QUIC、ICMP 和 IPv6 转发不支持。更新需要系统安装确认，首次需允许本应用安装 APK。
