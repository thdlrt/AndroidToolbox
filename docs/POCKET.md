# 手机访问电脑里的 DSH

在手机上直接打开电脑上运行的 DeepSeek Harness 网页界面（DSH Pocket），登录一次后自动保持会话。

## 电脑端

打开 DSH 的「设置 → 手机访问」，打开「局域网访问」。页面上会显示两件事，手机端只需要这两项：

- 二维码下面那一行地址，例如 `http://192.168.100.110:3081`。
- 「局域网访问密码」，例如 8 位数字；关掉密码开关就不需要密码。

电脑和手机要连同一个 Wi-Fi。电脑睡眠、换回环地址或关掉「局域网访问」后，手机端会连不上。

## 手机端

1. 打开工具箱的「手机访问」，填写电脑地址和访问密码，点「打开」。
2. 页面就是电脑上的那份界面，实时同步。地址支持直接粘贴，`192.168.100.110:3081` 和 `http://192.168.100.110:3081` 都能识别；只填主机和端口，不填路径。
3. 之后打开这个工具会直接进入页面，不需要再输密码。DSH 的会话 cookie 保存在本应用内，有效期 30 天，可用「连接设置 → 清除登录」立即清除。

页面右上角：刷新当前页面、连接设置。返回到工具箱再进来不会重新加载页面，输入到一半的内容仍在。

## 常见提示

- **密码错误**：DSH 登录页自己报错时，按页面提示重新输入即可；「访问密码」留空表示保持原密码不变。
- **无法完成登录握手**：手机浏览器（尤其 Safari）在纯 IP 的 http 地址上不保留 cookie 时会出现。本工具用应用内 WebView 保存 cookie，不会走到这一步；如果仍然出现，多半是电脑端 DSH 版本更新后握手流程有变。
- **连不上电脑界面**：电脑端没开「局域网访问」、手机不在同一 Wi-Fi，或地址里的 IP 变了。

DSH 页面本身是桌面排版，手机上内容偏大或偏空属正常现象，可以双指缩放查看细节。
